:::exercise{#exr-29-quiz} A last pattern quiz
For each short statement, name the technique and the chapter. Read the limit first.

1. A string of length up to 10⁵. Find the longest substring that uses at most two distinct letters.
2. *n* ≤ 10⁵ build steps, some of which must come before others. Print any valid order, or say that none exists.
3. *n* ≤ 20 weights, each up to 10⁹. Split them into two groups whose totals are as close as possible.
4. A tree with *n* ≤ 10⁵ nodes and *q* ≤ 10⁵ queries: the number of edges between *u* and *v*.
5. *n* ≤ 10⁵ workers, each available from time *s* to time *e* (times up to 10⁹), and *q* ≤ 10⁵ moments. For each moment, count the workers available.
6. *n* ≤ 10⁵ numbers up to 10⁶. Count the pairs whose gcd is exactly 1.

**Exercise 29.4.**

1. Sliding window with letter counts (Chapter 3), O(*n*): the condition "at most two distinct letters" stays true when the window shrinks.
2. Topological order by Kahn's algorithm (Chapter 15), O(*n* + *m*): if fewer than *n* steps come out, there is a cycle and no order exists.
3. Subset enumeration (Chapters 9 and 22): with *n* ≤ 20 there are 2²⁰ = 1,048,576 splits, and weights up to 10⁹ rule out a knapsack over sums.
4. Lowest common ancestors by binary lifting (Chapter 18): the distance is depth(*u*) + depth(*v*) − 2 · depth(lca(*u*, *v*)), O(log *n*) per query.
5. Sort the start times and the end times; the answer for moment *t* is the number of starts ≤ *t* minus the number of ends < *t*, two binary searches per moment (Chapter 6). The times are too large for a difference array indexed by time (Chapter 2).
6. Loops over multiples with inclusion–exclusion on the gcd (Chapter 10): count the pairs whose gcd is a multiple of each *d* from the number of values divisible by *d*, then subtract the counts for the multiples of *d*, from the largest *d* down. One pass over all multiples up to 10⁶ is Σ ⌊10⁶/*d*⌋ = 13,970,034 steps, and the method needs two.
