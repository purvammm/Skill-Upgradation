How to read this page

  • Method shows the call as you type it. takes lists the parameter types and returns the result type. E is the element type of a collection, K and V the key and value types of a map, T any object type.
  • What it does includes the edge cases: what happens on an empty structure, a missing key, or an index out of range (exception or null).
  • Cost is the time per call, with n the current size: O(1) O(log n) O(n) O(n log n). “Amortised” means an occasional slow call is averaged out over many fast ones.
  • Example: every example in a section starts again from the state shown in the grey box at the top of that section. A comment // → 5 is the value of that line; // list → [5, 3] is the state of list after the line; // throws X means that line throws exception X.
  • Untagged methods work in Java 8. A Java 11+ tag means you need that version or newer; check which Java the test platform runs before using one.
  • Press / to jump to the search box. Searching hides everything except matching methods.

Generics such as List<E> and Map<K, V> only take object types, so you write the wrapper: Integer, Long, Character, Boolean, Double. Java converts between int and Integer automatically (autoboxing), which costs time and memory and makes null possible.

Tip “Infinity” that survives addition

Integer.MAX_VALUE + 1 wraps to a negative number, so a distance of MAX_VALUE breaks dist[u] + w. Use a smaller sentinel: Integer.MAX_VALUE / 2, (int) 1e9, or Long.MAX_VALUE / 4 for long.

int INF = Integer.MAX_VALUE / 2;
int stillPositive = INF + INF;  // → 2147483646
long LINF = Long.MAX_VALUE / 4;

Number-theory helpers you write yourself

Math has no gcd or modular power. These two are short enough to type from memory. Divide before multiplying in the lcm to avoid overflow.

static long gcd(long a, long b) { return b == 0 ? a : gcd(b, a % b); }

static long power(long base, long exp, long mod) {      // base^exp % mod in O(log exp)
    long result = 1;
    base %= mod;
    while (exp > 0) {
        if ((exp & 1) == 1) result = result * base % mod;
        base = base * base % mod;
        exp >>= 1;
    }
    return result;
}

Enumerating subsets with a bitmask

Bitmask DP and brute force over subsets use these two loops. 2^n is fine up to about n = 20.

int[] items = {3, 5, 7};
int n = items.length;
List<Integer> sums = new ArrayList<>();
for (int mask = 0; mask < (1 << n); mask++) {          // every subset, 2^n of them
    int sum = 0;
    for (int i = 0; i < n; i++)
        if ((mask >> i & 1) == 1) sum += items[i];      // is item i in this subset?
    sums.add(sum);
}
// sums → [0, 3, 5, 8, 7, 10, 12, 15]

int m = 0b1011;
List<Integer> subs = new ArrayList<>();
for (int sub = m; sub > 0; sub = (sub - 1) & m) subs.add(sub);   // every non-empty submask of m
// subs → [11, 10, 9, 8, 3, 2, 1]

Monotonic stack: next greater element

Each index is pushed and popped at most once, so the whole loop is O(n). The same shape solves daily temperatures, stock span and largest rectangle in a histogram.

int[] a = {2, 1, 2, 4, 3};
int[] next = new int[a.length];
Deque<Integer> st = new ArrayDeque<>();                 // indexes; their values decrease from bottom to top
for (int i = a.length - 1; i >= 0; i--) {
    while (!st.isEmpty() && a[st.peek()] <= a[i]) st.pop();
    next[i] = st.isEmpty() ? -1 : a[st.peek()];
    st.push(i);
}
// next → [4, 2, 4, -1, -1]

Monotonic deque: sliding window maximum (LeetCode 239)

Dijkstra with a PriorityQueue (non-negative weights)

O((V + E) log V). Skipping stale entries replaces the “decrease key” operation that PriorityQueue does not have.

int n = 4;
int[][] edges = {{0, 1, 4}, {0, 2, 1}, {2, 1, 2}, {1, 3, 1}};   // from, to, weight (directed)
List<List<int[]>> g = new ArrayList<>();
for (int i = 0; i < n; i++) g.add(new ArrayList<>());
for (int[] e : edges) g.get(e[0]).add(new int[] {e[1], e[2]});
long[] dist = new long[n];
Arrays.fill(dist, Long.MAX_VALUE);
dist[0] = 0;
PriorityQueue<long[]> pq = new PriorityQueue<>((x, y) -> Long.compare(x[0], y[0]));   // {distance, node}
pq.offer(new long[] {0, 0});
while (!pq.isEmpty()) {
    long[] top = pq.poll();
    int u = (int) top[1];
    if (top[0] > dist[u]) continue;                 // stale entry: a shorter path was found already
    for (int[] e : g.get(u)) {
        if (dist[u] + e[1] < dist[e[0]]) {
            dist[e[0]] = dist[u] + e[1];
            pq.offer(new long[] {dist[e[0]], e[0]});
        }
    }
}
// dist → [0, 3, 1, 4]

    }
    int find(int x) {                               // root of x's group, with path halving
        while (parent[x] != x) { parent[x] = parent[parent[x]]; x = parent[x]; }
        return x;
    }
    boolean union(int a, int b) {                   // false if already in the same group
        int ra = find(a), rb = find(b);
        if (ra == rb) return false;
        if (size[ra] < size[rb]) { int t = ra; ra = rb; rb = t; }
        parent[rb] = ra;
        size[ra] += size[rb];
        groups--;
        return true;
    }
}

Trie (prefix tree)

Stores words character by character so that “is there a word with this prefix?” costs O(length of the prefix), independent of how many words are stored (LeetCode 208).

Definition used by the examples
static class Trie {
    Trie[] next = new Trie[26];
    boolean end;                                    // a word ends here
    void insert(String w) {
        Trie t = this;
        for (char c : w.toCharArray()) {
            if (t.next[c - 'a'] == null) t.next[c - 'a'] = new Trie();
            t = t.next[c - 'a'];
        }
        t.end = true;
    }
    Trie walk(String s) {
        Trie t = this;
        for (char c : s.toCharArray()) { t = t.next[c - 'a']; if (t == null) return null; }
        return t;
    }
    boolean search(String w) { Trie t = walk(w); return t != null && t.end; }
    boolean startsWith(String p) { return walk(p) != null; }
}

Fenwick tree (binary indexed tree)

Prefix sums with point updates, both O(log n). Without updates, a plain prefix-sum array (p[i + 1] = p[i] + a[i]) answers range sums in O(1).

Definition used by the examples
static class Fenwick {
    long[] t;                                       // 1-based inside
    Fenwick(int n) { t = new long[n + 1]; }
    void add(int i, long delta) {                   // a[i] += delta, i is 0-based
        for (i++; i < t.length; i += i & -i) t[i] += delta;
    }
    long sum(int i) {                               // a[0] + ... + a[i - 1]
        long s = 0;
        for (; i > 0; i -= i & -i) s += t[i];
        return s;
    }
    long rangeSum(int l, int r) { return sum(r + 1) - sum(l); }   // a[l..r] inclusive
}

static class FastReader {
    private final BufferedReader br;
    private StringTokenizer st;
    FastReader(InputStream is) { br = new BufferedReader(new InputStreamReader(is)); }
    String next() throws IOException {
        while (st == null || !st.hasMoreTokens()) {       // while, not if: skips blank lines
            String line = br.readLine();
            if (line == null) return null;                // end of input
            st = new StringTokenizer(line);
        }
        return st.nextToken();
    }
    int nextInt() throws IOException { return Integer.parseInt(next()); }
    long nextLong() throws IOException { return Long.parseLong(next()); }
}
