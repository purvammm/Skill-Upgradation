Generics such as List<E> and Map<K, V> only take object types, so you write the wrapper: Integer, Long, Character, Boolean, Double. Java converts between int and Integer automatically (autoboxing), which costs time and memory and makes null possible.

Tip: “Infinity” that survives addition

Integer.MAX_VALUE + 1 wraps to a negative number, so a distance of MAX_VALUE breaks dist[u] + w. Use a smaller sentinel: Integer.MAX_VALUE / 2, (int) 1e9, or Long.MAX_VALUE / 4 for long.

int INF = Integer.MAX_VALUE / 2;
int stillPositive = INF + INF;  // → 2147483646
long LINF = Long.MAX_VALUE / 4;

📄Number-theory helpers you write yourselfexample
static long gcd(long a, long b) { return b == 0 ? a : gcd(b, a % b); }

static long power(long base, long exp, long mod) {      // base^exp % mod in O(log exp)
    long result = 1;
    base %= mod;
    while (exp > 0) {
        if ((exp & 1) == 1) result = result * base % mod;
        base = base * base % mod;
        exp >>= 1;
    }
    return result;
}

📄Enumerating subsets with a bitmaskexample
int[] items = {3, 5, 7};
int n = items.length;
List<Integer> sums = new ArrayList<>();
for (int mask = 0; mask < (1 << n); mask++) {          // every subset, 2^n of them
    int sum = 0;
    for (int i = 0; i < n; i++)
        if ((mask >> i & 1) == 1) sum += items[i];      // is item i in this subset?
    sums.add(sum);
}

    long[] top = pq.poll();

    if (top[0] > dist[u]) continue;                 // stale entry: a shorter path was found already
    for (int[] e : g.get(u)) {

Union-Find (disjoint set union)

4 entries

Answers “are x and y in the same group?” while groups merge. With path compression and union by size, each call is effectively O(1) (inverse Ackermann, written α(n)). Use it for connected components, Kruskal's minimum spanning tree and cycle detection in undirected graphs.

📄Definition used by the examplesgiven
static class DSU {
    int[] parent, size;
    int groups;
    DSU(int n) {
        parent = new int[n];
        size = new int[n];
        groups = n;
        for (int i = 0; i < n; i++) { parent[i] = i; size[i] = 1; }
    }
    int find(int x) {                               // root of x's group, with path halving
        while (parent[x] != x) { parent[x] = parent[parent[x]]; x = parent[x]; }
        return x;
    }
    boolean union(int a, int b) {                   // false if already in the same group
        int ra = find(a), rb = find(b);
        if (ra == rb) return false;
        if (size[ra] < size[rb]) { int t = ra; ra = rb; rb = t; }
        parent[rb] = ra;
        size[ra] += size[rb];
        groups--;
        return true;
    }
}

Trie (prefix tree)

3 entries

Stores words character by character so that “is there a word with this prefix?” costs O(length of the prefix), independent of how many words are stored (LeetCode 208).

📄Definition used by the examplesgiven
static class Trie {
    Trie[] next = new Trie[26];
    boolean end;                                    // a word ends here
    void insert(String w) {
        Trie t = this;
        for (char c : w.toCharArray()) {
            if (t.next[c - 'a'] == null) t.next[c - 'a'] = new Trie();
            t = t.next[c - 'a'];
        }
        t.end = true;
    }
    Trie walk(String s) {
        Trie t = this;
        for (char c : s.toCharArray()) { t = t.next[c - 'a']; if (t == null) return null; }
        return t;
    }
    boolean search(String w) { Trie t = walk(w); return t != null && t.end; }
    boolean startsWith(String p) { return walk(p) != null; }
}

Fenwick tree (binary indexed tree)

3 entries

Prefix sums with point updates, both O(log n). Without updates, a plain prefix-sum array (p[i + 1] = p[i] + a[i]) answers range sums in O(1).

📄Definition used by the examplesgiven
static class Fenwick {
    long[] t;                                       // 1-based inside
    Fenwick(int n) { t = new long[n + 1]; }
    void add(int i, long delta) {                   // a[i] += delta, i is 0-based
        for (i++; i < t.length; i += i & -i) t[i] += delta;
    }
    long sum(int i) {                               // a[0] + ... + a[i - 1]
        long s = 0;
        for (; i > 0; i -= i & -i) s += t[i];
        return s;
    }
    long rangeSum(int l, int r) { return sum(r + 1) - sum(l); }   // a[l..r] inclusive
}

static class FastReader {
    private final BufferedReader br;
    private StringTokenizer st;
    FastReader(InputStream is) { br = new BufferedReader(new InputStreamReader(is)); }
    String next() throws IOException {
        while (st == null || !st.hasMoreTokens()) {       // while, not if: skips blank lines
            String line = br.readLine();
            if (line == null) return null;                // end of input
            st = new StringTokenizer(line);
        }
        return st.nextToken();
    }
    int nextInt() throws IOException { return Integer.parseInt(next()); }
    long nextLong() throws IOException { return Long.parseLong(next()); }
}

Traps, one line each

The mistakes that compile fine and then fail hidden test cases. Each links to the section that explains it.

Check these before you submit
  • int sums and products overflow silently: use long, and cast before multiplying: (long) a * b. Arithmetic
  • % keeps the sign of the left operand: use Math.floorMod for negative numbers. Math
  • Comparators written as a - b can overflow: use Integer.compare(a, b). Comparator
  • == on Integer, Long or String compares references: use equals, or unbox first. ArrayList
  • list.remove(3) removes index 3; list.remove(Integer.valueOf(3)) removes the value 3. ArrayList
  • map.get(k), floorKey, ceiling, poll and peek return null when there is nothing; unboxing that into int throws. HashMap
  • PriorityQueue.remove(x) and contains(x) are O(n), and printing a heap does not show sorted order. PriorityQueue
  • A TreeSet or TreeMap with a comparator treats “compares as 0” as a duplicate and drops it. TreeSet
  • int[] keys in a HashMap/HashSet compare by reference: use a List, a String or an encoded long. HashMap
  • Changing a collection inside a for-each loop over it throws ConcurrentModificationException: use removeIf or an Iterator. Iterator
  • s += x in a loop is O(n²): use StringBuilder. split takes a regex: escape . and |. String
  • result.add(path) in backtracking stores a reference: add new ArrayList<>(path). ArrayList
  • ArrayDeque rejects null: check children before offer in tree BFS. Stack
  • Recursion deeper than about 10⁴ frames can overflow the stack: switch to an explicit stack. Graphs
  • 1 << k with k ≥ 31 is wrong: use 1L << k. Bits
  • Scanner.nextInt() followed by nextLine() returns the empty rest of the line; and output in a PrintWriter is lost without flush(). Scanner
  • List.of, Map.of, String.repeat, isBlank, var and toList() need Java 9–16; if the platform runs Java 8 they do not compile. Version tags
