Lesson 1 · "Easy" is not LeetCode Easy

The Easy problem combines a number-theory trick with a tree technique. This plan therefore targets Codeforces 1400–2100 problems by week 3, and LeetCode is used only to learn each pattern.

Lesson 2 · Trust the samples, not the format text

In the Medium problem, the written input format puts p after the array. All three samples only work if p is read right after n. I checked this by running both readings: the written order gives 1, 0, 0 against the expected 2, 3, 1. Always check your parsing against the samples before you write the logic.

Lesson 3 · Partial marks are real marks

A brute force that is correct for small inputs passes the small test files. For the sample Hard problem, trying every subsequence works up to N ≈ 20. Never leave a problem blank.

Lesson 4 · Java-specific traps

Trees arrive as parent arrays with up to 10⁵ nodes, so a recursive DFS on a chain crashes with StackOverflowError. Products of values up to 10⁹ overflow int. Section 03 has the fixes.

1 · Input/output skeleton

This reader skips spaces and newlines alike, so it handles Infosys's one-value-per-line input and ordinary space-separated input. If the platform gives you a get_ans(...) stub and does the I/O itself, keep its signature exactly as given and put your logic in helper methods.

import java.io.*;
import java.util.*;

public class Main {
    static final long MOD = 1_000_000_007L;

    public static void main(String[] args) throws IOException {
        FastReader in = new FastReader(System.in);
        PrintWriter out = new PrintWriter(new BufferedWriter(new OutputStreamWriter(System.out)));

        int n = in.nextInt();              // works whether values are on one line or one per line
        long[] a = new long[n];
        for (int i = 0; i < n; i++) a[i] = in.nextLong();

        long sum = 0;
        for (long x : a) sum += x;
        out.println(sum);

        out.flush();                        // forgetting this = empty output = 0 marks
    }

    /** Token reader: skips spaces AND newlines, so "one value per line" input is handled. */
    static final class FastReader {
        private final DataInputStream in;
        private final byte[] buf = new byte[1 << 16];
        private int len = 0, ptr = 0;

        FastReader(InputStream is) { in = new DataInputStream(is); }

        private int read() throws IOException {
            if (ptr == len) {
                len = in.read(buf, 0, buf.length);
                ptr = 0;
                if (len <= 0) return -1;
            }
            return buf[ptr++];
        }

        long nextLong() throws IOException {
            int c = read();
            while (c != '-' && (c < '0' || c > '9')) {
                if (c == -1) throw new EOFException();
                c = read();
            }
            boolean neg = c == '-';
            if (neg) c = read();
            long r = 0;
            while (c >= '0' && c <= '9') { r = r * 10 + (c - '0'); c = read(); }
            return neg ? -r : r;
        }

        int nextInt() throws IOException { return (int) nextLong(); }

        String next() throws IOException {
            int c = read();
            while (c != -1 && c <= ' ') c = read();
            if (c == -1) throw new EOFException();
            StringBuilder sb = new StringBuilder();
            while (c > ' ') { sb.append((char) c); c = read(); }
            return sb.toString();
        }
    }
}

2 · Library (expand each one)

Modular arithmetic, nCr, gcd
// Modular arithmetic + nCr
static final long MOD = 1_000_000_007L;

static long power(long b, long e, long m) {
    long r = 1 % m;
    b %= m;
    if (b < 0) b += m;
    while (e > 0) {
        if ((e & 1) == 1) r = r * b % m;
        b = b * b % m;
        e >>= 1;
    }
    return r;
}

static long inv(long a) { return power(a, MOD - 2, MOD); } // MOD must be prime

static long[] fact, invFact;

static void initFact(int n) {
    fact = new long[n + 1];
    invFact = new long[n + 1];
    fact[0] = 1;
    for (int i = 1; i <= n; i++) fact[i] = fact[i - 1] * i % MOD;
    invFact[n] = inv(fact[n]);
    for (int i = n; i > 0; i--) invFact[i - 1] = invFact[i] * i % MOD;
}

static long nCr(int n, int r) {
    if (r < 0 || r > n) return 0;
    return fact[n] * invFact[r] % MOD * invFact[n - r] % MOD;
}

static long gcd(long a, long b) { while (b != 0) { long t = a % b; a = b; b = t; } return Math.abs(a); }

If the modulus is not prime (Infosys has used 10000), modular inverses don't exist. Build Pascal's triangle instead.

Smallest-prime-factor sieve
// Sieve with smallest prime factor
static int[] spf(int n) {
    int[] s = new int[n + 1];
    for (int i = 2; i <= n; i++) {
        if (s[i] == 0) {
            for (int j = i; j <= n; j += i) if (s[j] == 0) s[j] = i;
        }
    }
    return s; // s[x] == x  <=> x is prime (x >= 2)
}

To factorize x, repeat p = s[x]; x /= p. Each factorization takes O(log x).

DSU (union-find)
// DSU
static final class DSU {
    final int[] p, sz;
    DSU(int n) { p = new int[n]; sz = new int[n]; for (int i = 0; i < n; i++) { p[i] = i; sz[i] = 1; } }
    int find(int x) { while (p[x] != x) { p[x] = p[p[x]]; x = p[x]; } return x; }
    boolean union(int a, int b) {
        a = find(a); b = find(b);
        if (a == b) return false;
        if (sz[a] < sz[b]) { int t = a; a = b; b = t; }
        p[b] = a; sz[a] += sz[b];
        return true;
    }
}
Fenwick tree (BIT)
// Fenwick (1-indexed): point add, prefix sum
static final class Fenwick {
    final long[] t; final int n;
    Fenwick(int n) { this.n = n; t = new long[n + 1]; }
    void add(int i, long v) { for (; i <= n; i += i & -i) t[i] += v; }
    long sum(int i) { long s = 0; for (; i > 0; i -= i & -i) s += t[i]; return s; }
    long sum(int l, int r) { return sum(r) - sum(l - 1); }
}

For prefix maximum, which DP needs, change += to max. This only works when values never decrease. The sample Hard solution uses this version.

Segment tree (iterative, any associative operation)
// Iterative segment tree (0-indexed, half-open queries)
// Change identity + combine for sum / min / max / gcd.
static final class SegTree {
    final int n; final long[] t;
    static final long ID = 0;                              // gcd identity (sum: 0, min: +INF, max: -INF)
    static long op(long a, long b) { return gcd(a, b); }   // swap for Math.min / Math.max / a + b
    SegTree(long[] a) {
        n = a.length; t = new long[2 * n];
        for (int i = 0; i < n; i++) t[n + i] = a[i];
        for (int i = n - 1; i > 0; i--) t[i] = op(t[2 * i], t[2 * i + 1]);
    }
    void set(int i, long v) { for (t[i += n] = v; i > 1; i >>= 1) t[i >> 1] = op(t[i], t[i ^ 1]); }
    long query(int l, int r) { // [l, r)
        long resL = ID, resR = ID;
        for (l += n, r += n; l < r; l >>= 1, r >>= 1) {
            if ((l & 1) == 1) resL = op(resL, t[l++]);
            if ((r & 1) == 1) resR = op(t[--r], resR);
        }
        return op(resL, resR);
    }
}
Lazy segment tree (range add, range max)
// Lazy segment tree: range add, range max
static final class LazyMax {
    final int n; final long[] mx, lz;
    LazyMax(int n) { this.n = n; mx = new long[4 * n]; lz = new long[4 * n]; }
    private void push(int x) {
        if (lz[x] != 0) {
            for (int c = 2 * x; c <= 2 * x + 1; c++) { mx[c] += lz[x]; lz[c] += lz[x]; }
            lz[x] = 0;
        }
    }
    void add(int l, int r, long v) { add(1, 0, n - 1, l, r, v); } // inclusive
    private void add(int x, int lo, int hi, int l, int r, long v) {
        if (r < lo || hi < l) return;
        if (l <= lo && hi <= r) { mx[x] += v; lz[x] += v; return; }
        push(x);
        int mid = (lo + hi) >>> 1;
        add(2 * x, lo, mid, l, r, v);
        add(2 * x + 1, mid + 1, hi, l, r, v);
        mx[x] = Math.max(mx[2 * x], mx[2 * x + 1]);
    }
    long max(int l, int r) { return max(1, 0, n - 1, l, r); } // inclusive
    private long max(int x, int lo, int hi, int l, int r) {
        if (r < lo || hi < l) return Long.MIN_VALUE;
        if (l <= lo && hi <= r) return mx[x];
        push(x);
        int mid = (lo + hi) >>> 1;
        return Math.max(max(2 * x, lo, mid, l, r), max(2 * x + 1, mid + 1, hi, l, r));
    }
}

This is the structure behind the "split into K segments" DP problems (CF 833B, CF 1527E, AtCoder W).

Dijkstra
// Dijkstra (adjacency as int[]{to, w})
static long[] dijkstra(List<int[]>[] g, int src) {
    long[] d = new long[g.length];
    Arrays.fill(d, Long.MAX_VALUE);
    d[src] = 0;
    PriorityQueue<long[]> pq = new PriorityQueue<>((x, y) -> Long.compare(x[0], y[0]));
    pq.add(new long[]{0, src});
    while (!pq.isEmpty()) {
        long[] cur = pq.poll();
        int u = (int) cur[1];
        if (cur[0] != d[u]) continue;           // stale entry
        for (int[] e : g[u]) {
            long nd = d[u] + e[1];
            if (nd < d[e[0]]) { d[e[0]] = nd; pq.add(new long[]{nd, e[0]}); }
        }
    }
    return d;
}
Tree from a parent array, without recursion
// Tree from parent array: BFS order without recursion
// par[v] = parent of v (1-indexed nodes), par[root] = 0. Returns nodes in BFS order.
static int[] bfsOrder(int n, int[] par) {
    int[] head = new int[n + 1], nxt = new int[n + 1];
    Arrays.fill(head, -1);
    int root = -1;
    for (int v = 1; v <= n; v++) {
        if (par[v] == 0) root = v;
        else { nxt[v] = head[par[v]]; head[par[v]] = v; }
    }
    int[] order = new int[n];
    int qh = 0, qt = 0;
    order[qt++] = root;
    while (qh < qt) {
        int u = order[qh++];
        for (int c = head[u]; c != -1; c = nxt[c]) order[qt++] = c;
    }
    return order; // iterate backwards for "children before parent" (post-order DP)
}

Loop over order backwards to compute subtree values (children before parents). Loop forwards to push values from parent to child, as in rerooting.

LCA with binary lifting
// LCA with binary lifting (built from BFS order)
static final class LCA {
    final int LOG; final int[][] up; final int[] depth;
    LCA(int n, int[] par, int[] order) {
        int lg = 1; while ((1 << lg) <= n) lg++;
        LOG = lg; up = new int[LOG][n + 1]; depth = new int[n + 1];
        for (int v : order) {
            int p = par[v] == 0 ? v : par[v];
            up[0][v] = p;
            depth[v] = par[v] == 0 ? 0 : depth[p] + 1;
            for (int k = 1; k < LOG; k++) up[k][v] = up[k - 1][up[k - 1][v]];
        }
    }
    int lca(int a, int b) {
        if (depth[a] < depth[b]) { int t = a; a = b; b = t; }
        int diff = depth[a] - depth[b];
        for (int k = 0; k < LOG; k++) if (((diff >> k) & 1) == 1) a = up[k][a];
        if (a == b) return a;
        for (int k = LOG - 1; k >= 0; k--) if (up[k][a] != up[k][b]) { a = up[k][a]; b = up[k][b]; }
        return up[0][a];
    }
}
Binary search on the answer
// Binary search on the answer
// Smallest x in [lo, hi] with ok(x) true, assuming ok is false...false true...true.
interface Check { boolean ok(long x); }
static long firstTrue(long lo, long hi, Check c) {
    while (lo < hi) {
        long mid = lo + (hi - lo) / 2;
        if (c.ok(mid)) hi = mid; else lo = mid + 1;
    }
    return lo;
}
Deep recursion on a big-stack thread
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) {
        // Run the real work on a thread with a 128 MB stack so deep recursion doesn't crash.
        Thread t = new Thread(null, () -> {
            try { solve(); } catch (IOException e) { throw new UncheckedIOException(e); }
        }, "solver", 1 << 27);
        t.start();
    }

    static void solve() throws IOException {
        int n = 1_000_000;                                  // a path of 1e6 nodes
        System.out.println(depth(n));
    }

    static int depth(int k) { return k == 0 ? 0 : 1 + depth(k - 1); }
}

Tested with recursion depth 10⁶. Use it only when an iterative version would take too long to write.

Stress tester: how you grade yourself without a judge
import java.util.*;

/** Compare a fast solve() with an obviously-correct brute() on thousands of tiny random inputs. */
public class Stress {
    public static void main(String[] args) {
        Random rnd = new Random(1);
        for (int iter = 1; iter <= 100000; iter++) {
            int n = 1 + rnd.nextInt(8);                    // tiny inputs expose bugs fastest
            int[] a = new int[n];
            for (int i = 0; i < n; i++) a[i] = rnd.nextInt(21) - 10;
            long fast = solve(a), slow = brute(a);
            if (fast != slow) {
                System.out.println("Mismatch on iteration " + iter + ": " + Arrays.toString(a));
                System.out.println("fast=" + fast + "  brute=" + slow);
                return;                                     // smallest failing case is now on screen
            }
        }
        System.out.println("All random tests passed");
    }

    // Example: maximum subarray sum. Replace both methods with your problem.
    static long solve(int[] a) {                           // Kadane, O(n)
        long best = Long.MIN_VALUE, cur = 0;
        for (int x : a) { cur = Math.max(x, cur + x); best = Math.max(best, cur); }
        return best;
    }

    static long brute(int[] a) {                           // every subarray, O(n^2)
        long best = Long.MIN_VALUE;
        for (int l = 0; l < a.length; l++) {
            long s = 0;
            for (int r = l; r < a.length; r++) { s += a[r]; best = Math.max(best, s); }
        }
        return best;
    }
}

Use this for every Infosys repeat problem that has no online judge. Write the brute force first; it takes 5 minutes and catches most bugs.

04 · The 29-day plan

Day by day, 7 November to 5 December

There are five phases. Days 2–9 build the tools that Q1 and Q2 rely on. Days 10–16 cover DP, which is what Q3 usually is. Days 17–23 cover the trees and data structures that Infosys's harder problems use. Days 24–29 are Infosys's own problems under exam conditions.

Daily routine (about 5 h)
  1. Learn (40 min). Read the day's notes. Type the related template from memory and compile it.
  2. Solve (3 h). ★ problems first, then ●. Time limits: 25 min for easy problems, 45 for medium, 60 for hard. When time runs out, read the hint or editorial, close it, and code the solution from scratch.
  3. Stretch (40 min). ◆ problems if you're on the SP track. Otherwise, redo one ★ problem using stdin input.
  4. Review (30 min). Log every mistake in the error log. Re-solve one problem from 3 days ago without looking at your old code.
Rules that make this work
  • Practice in a plain editor and compile from the terminal (javac Main.java && java Main < in.txt). The exam lab may not have autocomplete.
  • For every CSES, AtCoder or Codeforces problem, read the input with FastReader, never Scanner.
  • Before coding, write one line: state / idea / complexity. If the complexity doesn't fit the limits, don't start coding.
  • Don't skip a mock day. Mocks are where the marks come from.
  • If you have a short day (3 h), do the ★ problems and the review only.

05 · Mock exams

Five full mocks

Every mock lasts 3 hours, in one sitting, under the same rules. The Codeforces problems were picked by rating to match the Q1/Q2/Q3 steps, and none of them appears in the daily lists. Codeforces doesn't give partial marks, but it does show the first failing test ("Wrong answer on test 7"). Use that as your partial-credit estimate.

Mock rules
  1. Timer set to 180 minutes, phone in another room, plain editor and terminal only.
  2. Minutes 0–15: read every problem. On paper, write the limits, your idea and its complexity for each.
  3. Solve the problem you're surest of first. That isn't always Q1.
  4. By minute 150, every problem has a submission, even if it's only a brute force.
  5. No edits in the last 10 minutes to code that already passes.
After the mock (60–90 min)
  1. Enter your scores below (estimated % of tests passed).
  2. For each unsolved problem, read the editorial, close it, and code the solution from scratch.
  3. Log the cause of each failure: misread, wrong idea, overflow, off-by-one, TLE, or I/O.

06 · Infosys repeat problems

Problems Infosys keeps reusing

Frequencies come from a community question bank that counts independent reports from 2019 to 2026. The statements are paraphrased. The approaches are mine, and I checked each one against a brute force on random inputs. Hints and approaches are folded, so try each problem first. Problems without an online judge are graded with the stress tester.

RPG: maximum monsters defeatedVery high (11 reports) · SP · 2022–2026

You start with e experience. Monster i requires experience ≥ power[i] and adds bonus[i] when defeated. You can fight them in any order, and losing a fight ends the run. Find the maximum number you can defeat. Input order: n, e, then n powers, then n bonuses, one value per line.

Hint

If you can beat a set of monsters, you can beat them in order of increasing power.

Approach

Sort the (power, bonus) pairs by power. Walk through them while e ≥ power, adding each bonus. Use long for e. O(n log n). This is correct when bonuses are non-negative; check the limits. Practice twin: LC 502 IPO.

Count arrays where each element divides the nextVery high (13) · DSE · 2021–2025

Count arrays of length K with values in 1..N where a[i] divides a[i+1]. Print the count mod 10000. Samples: (N=2, K=1) → 2, (2, 2) → 3, (3, 2) → 5.

Hint

Small K and N: dp[v] pushed to every multiple of v, in O(K·N log N). Large K: an array has at most ⌊log₂N⌋+1 distinct values.

Approach

Count strictly increasing divisor chains with s distinct values ending at each v, using DP over multiples. Each chain extends to a length-K array in C(K−1, s−1) ways, depending on where the values change. 10000 is not prime, so build C with Pascal's triangle, not inverses. The same problem with mod 10⁹+7 is LC 2338.

Longest non-decreasing subsequence with XOR ≥ MVery high (13) · DSE, SP · 2022–2026

This is the Hard problem of the official sample paper. The full solution is in Section 07, which you should open only after Mock 4.

Maximum XOR choosing at most N/2 elementsVery high (13) · SP · 2021–2026

N is even (N ≤ 120) and A[i] ≤ 10⁶. Choose at most N/2 elements, not necessarily consecutive, to maximise their XOR. Samples: [1, 2] → 2 (not 3, because of the cap); [1, 2, 4, 7] → 7.

Hint

A ≤ 10⁶ < 2²⁰, so there are only about a million possible XOR values. What is the fewest number of elements that produces each one?

Approach

XOR knapsack: dp[x] is the fewest elements whose XOR is x. For each element a, new[x] = min(old[x], old[x ^ a] + 1). That is O(N·2²⁰) ≈ 1.3·10⁸ simple steps. The answer is the largest x with dp[x] ≤ N/2. A shortcut: a linear basis has at most 20 vectors, so when N ≥ 40 the cap never binds and CSES 3191's answer is correct.

Smallest base where M has all identical digitsVery high (10) · SP · 2021–2026

M ≤ 10¹². Find the smallest base B in which every digit of M is the same. Samples: 41 → 40 ("11"), 34430 → 312 ("110 110").

Hint

For B > 10⁶, B² > 10¹² ≥ M, so M has at most two digits in that base.

Approach

Check bases 2..10⁶ directly; each check costs O(log M). If none works, M must be "dd" in base B, so M = d·(B+1). For each divisor d ≤ 10⁶ of M, B = M/d − 1 is valid when B > d. Take the smallest such B. B = M − 1 ("11") always works for M ≥ 3. The all-ones version of this problem is LC 483.

Pack gifts into exactly K consecutive boxes, maximise the total of distinct countsVery high (9) · SP · 2022–2026

N ≤ 35000, K ≤ 50. This is CF 833B The Bakery with the same limits (Day 21). An O(K·N²) DP with a running distinct count gets the small tests.

Split into k segments, minimise the sum of (last − first occurrence)PrepInsta SP set

n ≤ 35000, k ≤ 100. This is CF 1527E Partition Game (Day 21, ◆). When a[i] repeats, it adds i − prev[a[i]] to every split point before prev[a[i]], which is a range add.

Andy's vacation: cancel at most K obligationsHigh (5) · SP · 2021–2025

Days 1..N (N ≤ 10⁶) and M obligations on given days; several can fall on the same day. Cancel at most K of them and find the longest run of free consecutive days. Samples: (N=10, K=2, days 6 9 3 2 7) → 5; (N=7, K=0, days 3 4) → 3.

Approach

Count obligations per day, then slide a window over the days while the window's count is ≤ K. O(N + M). Pattern twin: LC 1004. The trap: two obligations on one day both have to be cancelled to free that day.

Minimum work to transport wine between housesHigh (6) · SP · 2022–2026

Houses in a line each buy (+) or sell (−) bottles, and the total is zero. Moving one bottle one house costs 1. Find the minimum total work. Judge: GfG Wine Buying and Selling.

Approach

The answer is Σ |prefix sum| over every gap between neighbouring houses, because each gap carries exactly the imbalance to its left. Use long.

Minimum railway platformsVery high (8) · SP · 2022–2026

Given arrival and departure times, find the fewest platforms so that no train waits. This is the maximum overlap, the same as LC 2406 (Day 4). Check whether a train arriving at the exact minute another departs needs a new platform; the statement decides this.

Arrange numbers to form the largest numberHigh (4) · SP · 2023–2026

This is LC 179 (Day 4). Sort strings with the comparator (b + a).compareTo(a + b) and return "0" if every number is zero.

Choose X in [0, K] to maximise Σ (X xor A[i])High (6) · 2021–2025
Hint

Bits are independent in a sum of XORs. Setting bit b of X to 1 contributes (n − cnt₁[b])·2ᵇ, and setting it to 0 contributes cnt₁[b]·2ᵇ.

Approach

Walk K's bits from the top, as in digit DP. While you match K exactly, each 1-bit of K gives one candidate: put 0 there and choose freely below, taking the better contribution for each lower bit. Also count X = K itself. Take the best candidate. This is O(31·31) after counting bits. Use long.

Gym: fewest exercises to drain energy E (each exercise usable at most twice)High (5) · SP · 2020–2025
Approach

Sort the drains in descending order and use each one twice until E ≤ 0. If E is still positive after all of them, print −1. The greedy is correct because only the count matters, so the largest drains are always best.

Longest increasing subsequence where every adjacent pair has (x & y)·2 < (x | y)High (4) · SP

Samples: [15, 6, 5, 12, 1] → 2; [9, 17, 2, 15, 5, 2] → 2; [17, 16, 12, 2, 8, 17, 17] → 3.

Hint

Try the condition on pairs whose highest set bit is the same, and on pairs where it differs.

Approach

The condition holds exactly when x and y have different highest set bits (I checked every pair up to 600). So the highest bit must strictly increase along the subsequence, and its length is at most 31. Keep best[b] = the longest chain ending with highest bit b, so each element costs 1 + max(best[0..h−1]). O(31·n).

Fewest days to make terrain strictly decreasing (day t allows changes of 2^(t−1))High (6) · SP · 2021–2025

The core idea is the same as CF 1338A Powered Addition: find the largest deficit you must fix, and the answer is that deficit's bit length. Adjust for "strictly" and for the direction of the change.

Largest subset of [1, N−1] whose product ≡ 1 (mod N)High (4) · 2023–2025

This is CF 1514C. Take every number coprime to N. If their product mod N isn't 1, drop the element equal to that product.

Count pairs with XOR < K whose sum is primeInterview coding task, Oct 2026

EASY · Tree beauty: perfect-square pairs per subtree
  1. x·y is a perfect square exactly when x and y have the same square-free kernel (the product of the primes with odd exponent). So the problem becomes: count pairs with equal kernels in every subtree.
  2. Computing the kernel for values up to 10⁹ is fast: divide out the primes ≤ 1000 (only 168 of them). What remains has no prime factor ≤ 1000 and is below 1009³, so it is 1, q, q² or q·r. q² drops out; anything else stays in the kernel.
  3. Small-to-large: each node keeps a map kernel → count. When merging a child into its parent, always merge the smaller map into the larger one. Adding c copies of a key the big map already holds b times creates b·c new pairs. Total cost O(n log n).
  4. Process nodes in reverse BFS order. A recursive DFS overflows the stack on a 10⁵-node chain.
import java.io.*;
import java.util.*;

/** Infosys sample paper, EASY: sum over u of (# pairs in subtree(u) whose product is a perfect square). */
public class Main {
    static final long MOD = 1_000_000_007L;
    static int[] smallPrimes;

    public static void main(String[] args) throws IOException {
        FastReader in = new FastReader(System.in);
        int n = in.nextInt();
        int[] par = new int[n + 1];
        for (int v = 1; v <= n; v++) par[v] = in.nextInt();
        long[] a = new long[n + 1];
        for (int v = 1; v <= n; v++) a[v] = in.nextLong();
        System.out.println(solve(n, par, a));
    }

    static long solve(int n, int[] par, long[] a) {
        buildSmallPrimes();
        // children lists + BFS order (no recursion: a 1e5 chain would overflow the stack)
        int[] head = new int[n + 1], nxt = new int[n + 1];
        Arrays.fill(head, -1);
        int root = 1;
        for (int v = 1; v <= n; v++) {
            if (par[v] == 0) root = v;
            else { nxt[v] = head[par[v]]; head[par[v]] = v; }
        }
        int[] order = new int[n];
        int qh = 0, qt = 0;
        order[qt++] = root;
        while (qh < qt) { int u = order[qh++]; for (int c = head[u]; c != -1; c = nxt[c]) order[qt++] = c; }

        @SuppressWarnings("unchecked")
        HashMap<Long, Integer>[] mp = new HashMap[n + 1];
        long[] pairs = new long[n + 1];
        for (int v = 1; v <= n; v++) { mp[v] = new HashMap<>(); mp[v].put(kernel(a[v]), 1); }

        long ans = 0;
        for (int i = n - 1; i >= 0; i--) {          // children are finished before their parent
            int v = order[i];
            ans += pairs[v];                          // beauty(v) is final now
            int p = par[v];
            if (p == 0) continue;
            HashMap<Long, Integer> big = mp[p], small = mp[v];
            if (big.size() < small.size()) { HashMap<Long, Integer> t = big; big = small; small = t; }
            long cross = 0;
            for (Map.Entry<Long, Integer> e : small.entrySet()) {
                int have = big.getOrDefault(e.getKey(), 0);
                cross += (long) have * e.getValue();
                big.put(e.getKey(), have + e.getValue());
            }
            pairs[p] += pairs[v] + cross;
            mp[p] = big;
            mp[v] = null;
        }
        return ans % MOD;
    }

    /** Square-free kernel: x*y is a perfect square  <=>  kernel(x) == kernel(y). */
    static long kernel(long x) {
        long k = 1;
        for (int p : smallPrimes) {                  // primes <= 1000 only (168 of them)
            if ((long) p * p > x) break;
            int e = 0;
            while (x % p == 0) { x /= p; e ^= 1; }
            if (e == 1) k *= p;
        }
        // x has no prime factor <= 1000 left (or x < p*p, so x is 1 or prime)
        // x <= 1e9 < 1009^3, so x is 1, q, q*q or q*r for primes q, r > 1000
        long s = (long) Math.sqrt((double) x);
        while (s * s > x) s--;
        while ((s + 1) * (s + 1) <= x) s++;
        if (s * s != x) k *= x;                      // q or q*r stays in the kernel; q*q vanishes
        return k;
    }

    static void buildSmallPrimes() {
        if (smallPrimes != null) return;
        List<Integer> ps = new ArrayList<>();
        for (int i = 2; i <= 1000; i++) {
            boolean pr = true;
            for (int d = 2; d * d <= i; d++) if (i % d == 0) { pr = false; break; }
            if (pr) ps.add(i);
        }
        smallPrimes = ps.stream().mapToInt(Integer::intValue).toArray();
    }

    static final class FastReader {
        private final DataInputStream in; private final byte[] buf = new byte[1 << 16]; private int len, ptr;
        FastReader(InputStream is) { in = new DataInputStream(is); }
        private int read() throws IOException {
            if (ptr == len) { len = in.read(buf, 0, buf.length); ptr = 0; if (len <= 0) return -1; }
            return buf[ptr++];
        }
        long nextLong() throws IOException {
            int c = read();
            while (c != '-' && (c < '0' || c > '9')) { if (c == -1) throw new EOFException(); c = read(); }
            boolean neg = c == '-'; if (neg) c = read();
            long r = 0; while (c >= '0' && c <= '9') { r = r * 10 + (c - '0'); c = read(); }
            return neg ? -r : r;
        }
        int nextInt() throws IOException { return (int) nextLong(); }
    }
}

Partial-credit fallback: for each node, collect its subtree and test all pairs. That is O(n³) and passes only tiny tests, but it is far better than a blank submission.

MEDIUM · Good subsequence with gcd exactly p, under updates
  1. Only multiples of p can be in the subsequence. Let g be the gcd of all multiples of p. If g ≠ p, every subset has gcd ≥ g > p, so the answer is NO.
  2. If g = p and at least one element isn't a multiple of p, take all the multiples. That subsequence is shorter than n, so the answer is YES.
  3. If every element is a multiple of p: divide by p, so the gcd of everything is 1. Any value ≤ 10⁵ has at most 6 distinct primes (2·3·5·7·11·13·17 > 10⁵). So some subset of at most 7 elements already has gcd 1. With n ≥ 8 the answer is YES; with n ≤ 7, try removing each element.
  4. Maintain g with a gcd segment tree in which non-multiples are stored as 0 (gcd(0, x) = x), plus a counter of non-multiples. Each query costs O(log n).
  5. Input order: n, p, the array, q, the column count (2), then the queries. This differs from the written format; see Lesson 2.
import java.io.*;
import java.util.*;

/**
 * Infosys sample paper, MEDIUM: after each point update, does a non-empty subsequence
 * of length < n with gcd exactly p exist? Count YES answers.
 * NOTE: the samples put p BEFORE the array (the PDF's written format says after it).
 */
public class Main {
    public static void main(String[] args) throws IOException {
        FastReader in = new FastReader(System.in);
        int n = in.nextInt();
        int p = in.nextInt();
        int[] a = new int[n];
        for (int i = 0; i < n; i++) a[i] = in.nextInt();
        int q = in.nextInt();
        int cols = in.nextInt();                    // always 2, read and ignore
        int[][] qs = new int[q][2];
        for (int i = 0; i < q; i++) { qs[i][0] = in.nextInt(); qs[i][1] = in.nextInt(); }
        System.out.println(solve(n, p, a, qs));
    }

    static long solve(int n, int p, int[] a, int[][] qs) {
        a = a.clone();
        int size = 1; while (size < n) size <<= 1;
        int[] t = new int[2 * size];               // gcd of elements divisible by p (others stored as 0)
        int notDiv = 0;
        for (int i = 0; i < n; i++) {
            if (a[i] % p == 0) t[size + i] = a[i]; else notDiv++;
        }
        for (int i = size - 1; i > 0; i--) t[i] = gcd(t[2 * i], t[2 * i + 1]);

        long yes = 0;
        for (int[] qu : qs) {
            int i = qu[0] - 1, v = qu[1];
            if (a[i] % p != 0) notDiv--;
            a[i] = v;
            if (a[i] % p != 0) notDiv++;
            int pos = size + i;
            t[pos] = (a[i] % p == 0) ? a[i] : 0;
            for (pos >>= 1; pos > 0; pos >>= 1) t[pos] = gcd(t[2 * pos], t[2 * pos + 1]);

            int g = t[1];                            // gcd of all multiples of p (0 if none)
            boolean ok;
            if (g != p) ok = false;                  // every subset gcd is a multiple of g
            else if (notDiv > 0) ok = true;          // take all multiples: length < n
            else if (n >= 8) ok = true;              // a/p <= 1e5 has <= 6 primes -> gcd-1 subset of size <= 7
            else ok = existsDropOne(a, p);           // n <= 7: try removing each element
            if (ok) yes++;
        }
        return yes;
    }

    static boolean existsDropOne(int[] a, int p) {
        int n = a.length;
        for (int skip = 0; skip < n; skip++) {
            int g = 0;
            for (int j = 0; j < n; j++) if (j != skip) g = gcd(g, a[j]);
            if (g == p) return true;
        }
        return false;
    }

    static int gcd(int x, int y) { while (y != 0) { int r = x % y; x = y; y = r; } return x; }

    static final class FastReader {
        private final DataInputStream in; private final byte[] buf = new byte[1 << 16]; private int len, ptr;
        FastReader(InputStream is) { in = new DataInputStream(is); }
        private int read() throws IOException {
            if (ptr == len) { len = in.read(buf, 0, buf.length); ptr = 0; if (len <= 0) return -1; }
            return buf[ptr++];
        }
        long nextLong() throws IOException {
            int c = read();
            while (c != '-' && (c < '0' || c > '9')) { if (c == -1) throw new EOFException(); c = read(); }
            boolean neg = c == '-'; if (neg) c = read();
            long r = 0; while (c >= '0' && c <= '9') { r = r * 10 + (c - '0'); c = read(); }
            return neg ? -r : r;
        }
        int nextInt() throws IOException { return (int) nextLong(); }
    }
}
HARD · Longest non-decreasing subsequence with XOR ≥ M
  1. Values are ≤ N ≤ 1000 < 1024, so any XOR fits in 10 bits. Add that XOR as a DP dimension.
  2. Keep fw[x], a Fenwick tree over values that stores the longest subsequence with XOR x ending in a value ≤ v.
  3. For each element v, and for each target x, look up the best length with XOR x ^ v ending at a value ≤ v, then add 1. Compute all 1024 candidates before writing any of them, so v isn't used twice.
  4. Cost: N · 1024 · log N ≈ 2·10⁷ steps. The answer is the maximum over x ≥ M.
import java.io.*;
import java.util.*;

/** Infosys sample paper, HARD: longest non-decreasing subsequence whose XOR is >= M. */
public class Main {
    public static void main(String[] args) throws IOException {
        FastReader in = new FastReader(System.in);
        int n = in.nextInt();
        int m = in.nextInt();
        int[] a = new int[n];
        for (int i = 0; i < n; i++) a[i] = in.nextInt();
        System.out.println(solve(a, m));
    }

    // fw[x] = Fenwick over values; prefix max of "longest subsequence with XOR x ending in value <= v"
    static int solve(int[] a, int m) {
        int maxV = 1;
        for (int x : a) maxV = Math.max(maxV, x);
        int B = 1;
        while (B <= maxV) B <<= 1;                   // every XOR of values <= maxV is < B
        int[][] fw = new int[B][maxV + 1];
        int[] cand = new int[B];
        for (int v : a) {
            for (int x = 0; x < B; x++) {
                int best = query(fw[x ^ v], v);      // extend a subsequence whose XOR was x ^ v
                cand[x] = best > 0 ? best + 1 : 0;
            }
            cand[v] = Math.max(cand[v], 1);          // start a new subsequence with v alone
            for (int x = 0; x < B; x++) if (cand[x] > 0) update(fw[x], v, cand[x]);
        }
        int ans = 0;
        for (int x = m; x < B; x++) ans = Math.max(ans, query(fw[x], maxV));
        return ans;
    }

    static int query(int[] f, int i) { int r = 0; for (; i > 0; i -= i & -i) r = Math.max(r, f[i]); return r; }
    static void update(int[] f, int i, int v) { for (; i < f.length; i += i & -i) if (f[i] < v) f[i] = v; }

    static final class FastReader {
        private final DataInputStream in; private final byte[] buf = new byte[1 << 16]; private int len, ptr;
        FastReader(InputStream is) { in = new DataInputStream(is); }
        private int read() throws IOException {
            if (ptr == len) { len = in.read(buf, 0, buf.length); ptr = 0; if (len <= 0) return -1; }
            return buf[ptr++];
        }
        long nextLong() throws IOException {
            int c = read();
            while (c != '-' && (c < '0' || c > '9')) { if (c == -1) throw new EOFException(); c = read(); }
            boolean neg = c == '-'; if (neg) c = read();
            long r = 0; while (c >= '0' && c <= '9') { r = r * 10 + (c - '0'); c = read(); }
            return neg ? -r : r;
        }
        int nextInt() throws IOException { return (int) nextLong(); }
    }
}
